# OpenBook E-Reader

## Overview
OpenBook is a cutting-edge electronic reading device built around the ESP32-C6 microcontroller. This sophisticated gadget integrates multiple sensors and interfaces to deliver an energy-efficient reading experience with extended functionality.

## Hardware Capabilities

### Processing & Connectivity
The ESP32-C6 serves as the heart of OpenBook, providing Wi-Fi 6 and Bluetooth 5.0 LE connectivity. Its extensive GPIO capabilities enable seamless integration with various peripheral components.

### Display Technology
The e-paper display connects through an SPI interface and utilizes the BD5229G-TR driver for voltage management. MOSFET-controlled power distribution enables complete shutdown when not in use, significantly enhancing energy efficiency.

### Environmental Monitoring
The BME688 sensor delivers comprehensive environmental data including temperature, humidity, barometric pressure, and air quality (VOC) readings via I2C interface.

### Power Systems
The device features:
- MCP73831-based charging circuit supporting up to 500mA charging current
- MAX17048G+T10 battery monitoring system providing detailed charge level information
- Energy-efficient design for extended reading time

| Component         | Connected Pins      | Protocol | Function                               |

| BME688 Sensor     | IO8, IO10           | I2C      | Environmental monitoring               |
| SD Card Interface | IO7                 | SPI      | External storage                       |
| RTC Module        | IO8, IO10           | I2C      | Real-time clock (shared I2C bus)       |
| USB Interface     | IO16, IO17          | UART     | Programming and debugging              |

## Implementation Process

1. Electronic schematic design and ESP32-C6 component integration
2. 2D layout development and component placement
3. Signal and power trace routing
4. Ground plane implementation on both PCB layers
5. Trace width and clearance rule application
6. Strategic connector positioning (Qwiic, USB-C)
7. Test pad placement for debugging
8. 3D model generation and mechanical compatibility verification

## Technical Notes

- Test points have been strategically positioned near board edges and critical components for easy access during testing and debugging
- Surface-mount diode pad sizes were adjusted from initial specifications to ensure reliable electrical connections and easier assembly
- Trace routing utilizes both top and bottom PCB layers for efficient signal and power distribution
- Ground planes have been implemented on both layers to optimize electrical performance
